#### 🏢 IMS — Multi-Tenant ERP Platform

<!-- TODO: swap in the repo link once it's public/pinned -->
A multi-tenant, modular ERP platform (inventory, asset management, employee management, user/permission management) with physically isolated per-tenant SQL Server databases, a shared identity control plane, real-time permission invalidation over SSE, and four client surfaces: web (Next.js), mobile (React Native/Expo), a Windows desktop launcher (.NET/WPF), and a REST API (Node/Express).

- 🏗️ Two-plane multi-tenant architecture — a shared identity control-plane DB + one physically isolated SQL Server database per tenant, with per-request routing via `AsyncLocalStorage`
- 🔒 Fail-closed, deny-wins RBAC with 200+ granular permissions and real-time SSE-based session/permission invalidation
- 🧪 CI pipeline that provisions a real SQL Server instance and a brand-new tenant from migrations alone on every PR
- 🚀 Owns the full stack: Next.js/React frontend, Express/TypeORM backend, React Native mobile client, and a WPF desktop tool, plus CI/CD and deployment

#### 🎨 BlockMural — On-Chain Collaborative Pixel Canvas (Web3)

<!-- TODO: swap in the repo link once it's public/pinned; project is a personal test/experiment -->
A decentralized, collaborative pixel canvas (r/place-style) that lives **entirely on-chain** — anyone pays a small fee to paint a pixel, the canvas evolves in time-boxed epochs, and each epoch can be minted as an NFT whose image is generated **as SVG directly by the smart contract**, with no IPFS, metadata server, backend, or indexer anywhere in the stack. Built solo as a test project to explore gas-optimized Solidity and real-time Web3 frontend patterns.

- 🧪 100% test coverage: 73 Foundry unit/fuzz/invariant tests, plus formal/symbolic verification (Halmos) proving storage-packing correctness for every possible input
- ⛽ Gas-optimized nibble-packed storage, pull-payment withdrawals, and CEI-hardened reentrancy protection — with measured before/after gas tradeoffs documented in-repo
- 🔌 No backend, no indexer: a wagmi/viem frontend reads live from the chain, with real-time event-driven pixel updates and zero polling
- 🛡️ 6-job CI pipeline: coverage gate, gas-regression snapshot, ABI-drift check, Slither static analysis, gitleaks, and full Playwright E2E against a live local Anvil chain
- 🚧 Fully built, tested, and verified — public testnet deployment in progress, not yet live

#### 🧭 Codex of the Wayfarer — Sci-Fi CYOA/RPG (Hobby Project)

<!-- TODO: swap in the repo link once it's public/pinned -->
A desktop choose-your-own-adventure / RPG set in a "cold war galaxy" universe — a data-driven narrative and tactical-combat game with a full save system, built as a web app and packaged into a native Windows desktop app. A short hobby project (~21K LOC across 67+ components) built solo to explore game architecture and Electron packaging.

- 🗂️ Fully data-driven design: all narrative/game content lives in JSON, consumed by pure-function "engines" (combat, dialogue branching, quests, world simulation) — no hidden mutation, no external state library

- 💾 Dual-backend save system (`localStorage` + Electron IPC/file-based) with a versioned, backward-compatible migration step
